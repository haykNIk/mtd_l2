# 5 (штраф). Git Rebase

Команда [git rebase](https://git-scm.com/docs/git-rebase) позволяет внести коммиты из другой ветки в текущую.
В отличие от команды `git merge`, `rebase` не создаёт merge commit, а действует следующим образом:

1. ищет самый последний коммит, общий в обоих ветках
1. удаляет из нашей ветки все коммиты начиная с этой точки
1. переносит все коммиты из другой ветки в нашу
1. добавляет изменения из удалённых коммитов поверх привнесённых (шаг за шагом, создавая столько же коммитов, сколько было удалено до этого).
При возникновении конфликтов пользователю предлагается решить их и продолжить `rebase`.

В рамках задания выполните следующие шаги.

1. из ветки `develop` создайте ветки `refactor/comment` и `feature/enlarge_circle`
1. в ветке `refactor/comment` добавьте комментарии к методу `draw` класса `Circle`, кратко описав, что этот метод делает. Выполните `git commit`  
1. в ветке `feature/enlarge_circle` уберите константность переменной `m_radius` и сделайте метод для изменения радиуса. Выполните `git commit`
1. влейте `refactor/comment` в `develop` через Pull Request.
1. Сохраните граф недавних коммитов в файл:
    ```bash
    git log --oneline --abbrev-commit --all --graph -n 8 > graph_before.txt
    ```
1. находясь в ветке `feature/enlarge_circle`, выполните команду `git rebase main` (и затем `git push --force-with-lease`).
